# Đặc tả kỹ thuật có thể tái sử dụng

Checklist W1–W4 cũ đã được thay bằng [kế hoạch 7 người / 3 tuần](../sprint-3-weeks/README.md).

Giữ [DATA-AND-FLOWS](DATA-AND-FLOWS.md) và [EXAMPLES](EXAMPLES.md) vì chứa fields, API, trạng thái, thuật toán và ví dụ có thể tái sử dụng. Đây là tài liệu tham chiếu: phạm vi, lịch và ownership hiện hành theo sprint mới; contract thực tế phải được consumer review trước triển khai.
