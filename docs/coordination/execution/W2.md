- [ ] W2-QQ-04 — `content.generate` chỉ approved brief version: English article/FAQ/meta và một social text variant từ source version. Đánh dấu claim→source refs, missing rent/address/availability không chèn con số; rule title/meta/headings/brand/schema trước quality output. Không publish hoặc tự approve; media chỉ script/prompt text nếu scope đã có.
- [ ] W2-QQ-05 — Eval research/score/strategy/brief/content + invalid JSON/provider timeout/caps; một repair tối đa trong tổng provider calls/job. Ngày10 human review draft/strategy/brief qua API có audit, demo journey và capacity decision publish/metrics/experiment, ghi scope/risk changes.
